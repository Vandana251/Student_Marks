## 📌 Project Overview
A targeted data analytics notebook evaluating student examination scores, grading distributions, passing percentages, and score variance.

---

## 📂 Repository Contents
- **`10.Student_marks.ipynb`**: Jupyter notebook demonstrating data importing, descriptive statistics, outlier inspection, and visual distribution curves.
- **`eda_sample_dataset1.csv`**: Raw dataset containing student scores and assessment marks.

---

## 📊 Visualizations Included
1. **Histogram & KDE**: Visualizing test score distributions and skewness.
2. **Box Plots**: Identifying high and low score outliers across different student groups.
3. **Correlation Matrix**: Measuring relationships among scores across multiple tests.
